# Excuse Generator

A simple Python script that builds a random excuse by combining a who, a what, and a when.

## Example output

```
my bird pissed before the class
```

## How it works

The script picks one item at random from each list:

- **who** — who caused the problem
- **what** — what they did
- **when** — when it happened

Then it prints a full excuse sentence.

## Requirements

- Python 3

## How to run

```bash
python3 excuse_generator.py
```

Each run prints a new random excuse.
